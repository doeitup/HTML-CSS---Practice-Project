1. Simple Contact Form

This project contains a basic contact form designed using HTML and CSS. The form is responsive and user-friendly, aimed at collecting user information such as name, email, and message.

2. Features
- Clean and simple layout
- Responsive design suitable for different screen sizes
- Form fields include: Name, Email, Message, and Submit button
- Styled with CSS for a modern and visually appealing look

3. Technologies Used
- HTML5
- CSS3

4. Purpose
The purpose of this project is to practice frontend development skills by creating a functional and aesthetically pleasing contact form. It helps in understanding form structure, styling, and responsive design basics.
